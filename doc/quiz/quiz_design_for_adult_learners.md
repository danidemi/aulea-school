# Quiz Design for Adult Learning — Summary

## Core Principle
Quizzes are learning tools, not just assessment tools. The **testing effect** shows that active retrieval strengthens memory more than passive review.

## Key Frameworks
- **Testing effect / retrieval practice** — active recall > passive review
- **Formative vs. summative** — low-stakes, frequent quizzes outperform high-stakes rare ones for adults
- **Desirable difficulties (Bjork)** — spacing + interleaving + moderate effort improve retention
- **Andragogy (Knowles)** — adults need relevance, autonomy, and connection to prior experience
- **Self-Determination Theory** — engagement requires autonomy, competence, relatedness
- **Bloom's Taxonomy** — mix recall, application, and analysis-level questions
- **Generative learning (Wittrock)** — constructing answers > selecting them

## Question Formats — Recall vs. Recognition

| Format | Learning Value | Cost | Best Use |
|---|---|---|---|
| Open/short-answer | Highest (recall + generative) | High grading effort | Key concepts, application |
| Single-answer MCQ | Moderate (depends on distractor quality) | Low | Frequent formative checks |
| Multi-answer MCQ | Moderate, noisier scoring | Low–moderate | Overlapping concepts, used sparingly |
| True/False | Lowest | Very low | Warm-ups only |
| Matching/sequencing | Moderate (relational knowledge) | Low–moderate | Processes, taxonomies |

## Practical Takeaways
- Mix formats to sustain engagement and reduce fatigue
- Give immediate feedback (prevents weak distractors from implanting misconceptions)
- Use scenario-based, not pure-definition, questions for adults
- Reserve open questions for the most important concepts; use MCQ for frequent low-stakes checks
